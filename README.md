# Молочка — болезни молочной железы по КР РОАГ 2024

PWA для врача на приёме/дежурстве. Работает офлайн (GitHub Pages).

**Источники:** КР «Воспалительные заболевания молочных желез» 2024 (ID 858_1); КР «Доброкачественная дисплазия молочной железы» 2024 (ID 598); лексикон ACR BI-RADS 5th ed. (для тренажёра).

Вкладки: Учёба (Мастит, ДДМЖ: конспект · тест · задачи · карточки) · Мастит (лактационный / нелактационный / младенцы / дети) · ДДМЖ: маршрутизация · Масталгия: терапия · BI-RADS: справочник · Тренажёр BI-RADS (18 кейсов со схемами УЗИ/ММГ).

Под каждым пунктом — УУР/УДД и раскрывающаяся цитата КР. Кнопка «Скопировать тактику» — текст в историю.

Инструмент поддержки решений; не заменяет клиническое мышление и инструкции к препаратам.
